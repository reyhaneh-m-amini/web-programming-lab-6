# Web Programming Assignment 6 - Post Dashboard

## 1. File Organization

```assignment6/
src/
├── api/
│   └── postsApi.js       # Fetches posts from the API
├── components/
│   ├── FilterForm.jsx    # Filters posts with an input
│   ├── Post.jsx          # Displays one post
│   └── PostList.jsx      # Displays the list of posts
├── reducer/
│   └── postsReducer.js   # Manages the posts state
├── App.jsx               # Main component
├── App.css               # Styles the dashboard
├── index.css             # Global styles
└── main.jsx              # Renders the React app
```

## 2. Challenges

I had some problems with fetching the posts from the API and showing them on the page. Figuring out how to filter the posts and run the final program properly was also a challenge.
